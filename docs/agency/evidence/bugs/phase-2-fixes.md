Harness corrections: anonymous media denial initially reused a login context containing cookies; it now uses a fresh context without weakening 401/404 checks. Calendar testing now verifies the full accessible label while visual cards remain compact. Workspace status has a distinct accessible name. The replay runner preserves SDK aliases and processes histories in one replay worker, avoiding native-runtime reuse after shutdown. An interrupted build/start run and an overlapping leftover test process were excluded; final evidence comes from one sequential suite after confirmed build/start completion.
